# AI-Powered Vehicle Recognition System  

## Overview  
This project is an **Automatic Number-Plate Recognition (ANPR) System** powered by **computer vision**. The system identifies vehicles and their license plates, maintains a database, and provides a user portal for supervision.  

## Features  
- **Computer Vision-Based Detection**: Uses **Optical Character Recognition (OCR)** to read number plates.  
- **Automated Data Storage**: Replaces traditional pen-and-paper tracking with a **centralized database**.  
- **Improved Efficiency & Security**: Enhances accuracy, reliability, and data retrieval.  

## System Architecture  
- **Vehicle Detection** using YOLO-based deep learning models.  
- **License Plate Recognition** with OCR techniques.  
- **Database Management** for vehicle entry records.  
- **User Dashboard** to monitor vehicle logs and statistics.  

## Technologies Used  
- **Python**  
- **OpenCV**  
- **YOLOv8**  
- **EasyOCR**  
- **Flask/Django** (for backend)  
- **React.js** (for frontend)  

## Challenges Faced  
- Finding a large enough dataset for training.  
- Computational power limitations.  
- Optimizing model performance to reduce overfitting.  

## Future Work  
- Enhance adaptability to different environmental conditions.  
- Improve system performance with multi-threading and socket handling.  
- Introduce a **multi-modal recognition system** for better accuracy.
